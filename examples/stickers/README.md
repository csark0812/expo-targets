# Stickers example

Asset-only iMessage sticker pack (no `withTargetsMetro`). Host shows pack status for Maestro smoke.

Pack character: **Bip** (sage body, cream vest, minimal **dot-eye** face — locked in `stickers/bip.png`; mood stickers regen from that base). Grid size is **regular** (plugin default): provide sticker PNGs at **408×408 @3x**.

## OS path

1. Build and run on iOS
2. Messages → Stickers → Fun Stickers
